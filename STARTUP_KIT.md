## ☁️ Program Specifics & Strategy

### 1. Microsoft for Startups Founders Hub (Likeliest to Accept)
*   **Link**: [foundershub.startups.microsoft.com](https://foundershub.startups.microsoft.com/)
*   **Strategy**: This is the easiest entry. You usually get $1,000 - $5,000 Azure credits + free OpenAI credits immediately upon acceptance.
*   **Key Requirement**: Valid LinkedIn profile.

### 2. Google for Startups Cloud Program (Best for You)
*   **Link**: [cloud.google.com/startup](https://cloud.google.com/startup)
*   **Strategy**: You are using **Gemini** heavily. Mention this!
*   **Tier**: Apply for the "Start Tier" first.
*   **AI Special**: Once accepted, look for the "AI Startup" track. Since your core value prop is AI, you might qualify for the $350k tier later if you show traction.
*   **Key Requirement**: Domain email (`@ice.bio`) is mandatory.

### 3. AWS Activate Founders
*   **Link**: [aws.amazon.com/activate/founders](https://aws.amazon.com/activate/founders/)
*   **Benefits**: $1,000 credits.
*   **Strategy**: Good for covering basic hosting if you move off Vercel, or for Bedrock usage.
*   **Key Requirement**: Must not have received credits before. Company website must be live.

### 4. DigitalOcean Hatch (Alternative)
*   **Link**: [digitalocean.com/hatch](https://www.digitalocean.com/hatch)
*   **Strategy**: Good back up. Generally friendly to developer tools.
