# OpenLovable Prompt: Premium Developer Portfolio

## Project Name
`brianrice-portfolio`

## Prompt for OpenLovable

```
Create a premium developer portfolio website for Brian Rice with the following:

DESIGN:
- Modern, clean design with glassmorphism effects
- Gradient accents (blue/purple theme)
- Dark mode toggle
- Smooth animations and transitions
- Fully responsive (mobile, tablet, desktop)

SECTIONS:
1. Hero Section:
   - Name: Brian Rice
   - Title: Full-Stack Developer & Dashboard Specialist
   - Tagline: "Building premium React dashboards and SaaS interfaces"
   - CTA buttons: "View Projects" and "Contact Me"
   - Stats: 8 Dashboards Built, 100% Production Ready, AI-Powered

2. About Section:
   - Professional bio
   - Skills: React, TypeScript, Tailwind CSS, Node.js, AI Integration
   - Years of experience
   - Specialization in dashboard development

3. Services Section:
   - Custom Dashboard Development
   - SaaS Interface Design
   - AI Integration
   - Full-Stack Development
   Each with icon, description, and pricing range

4. Projects Showcase:
   - Grid layout with cards
   - Featured: Pulse Analytics, Echo Control, VibeFlow, Nexus Insights, CoreOps, ShopCore, BookFlow, HealthMetrics
   - Each card shows: screenshot placeholder, title, description, tech stack, "Live Demo" and "Buy Now" buttons
   - Link to live demos on Vercel

5. Testimonials (placeholder):
   - 3 testimonial cards
   - Client name, company, quote, rating

6. Contact Section:
   - Email: brian@brianrice.dev
   - Social links: GitHub, LinkedIn, Twitter
   - Contact form (name, email, message)

FEATURES:
- Smooth scroll navigation
- Sticky header with navigation
- Animated section reveals on scroll
- Hover effects on cards
- Professional typography (Inter or similar)
- SEO optimized meta tags

TECH STACK:
- React + Vite
- Tailwind CSS
- Lucide React icons
- Framer Motion for animations (optional)

Make it look premium, modern, and professional - something that showcases high-value work.
```

```
Include:

```

## What to Do

1. **Go to your OpenLovable interface** (localhost:3000 or wherever it's running)
2. **Create new project**: "brianrice-portfolio"
3. **Paste the prompt** (use the shorter one to start)
4. **Let it generate** the initial version
5. **Refine with follow-up prompts**:
   - "Add glassmorphism to project cards"
   - "Make the hero section more impactful with larger text"
   - "Add smooth scroll animations"
   - "Update project cards to link to live Vercel demos"

## After Generation

1. **Update project links** to your live Vercel URLs
2. **Add real content** (bio, services, pricing)
3. **Deploy to Vercel** 
4. **Point brianrice.dev** to the deployment

This will give you a professional portfolio in minutes instead of hours!
