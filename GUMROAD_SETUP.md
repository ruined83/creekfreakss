# Step-by-Step: Set Up Gumroad Store

## Overview
Create your Gumroad store and list all 8 dashboards for sale. Time: 30-45 minutes.

---

## Step 1: Create Gumroad Account (5 min)

1. Go to: https://gumroad.com
2. Click **Start Selling**
3. Sign up with email or Google
4. Verify your email
5. Complete profile:
   - Name: Brian Rice
   - Username: brianrice (or your choice)
   - Profile photo (optional)

---

## Step 2: Connect Bank Account (5 min)

1. Go to **Settings** → **Payments**
2. Click **Connect Bank Account**
3. Enter bank details (for payouts)
4. Verify identity (if required)

**Note**: You can skip this and add later, but you'll need it to receive payments.

## Step 6: Set Up Delivery (5 min)

For each product:

1. Create a private GitHub repo (or use existing)
2. Add all dashboard code
3. In Gumroad, set delivery to:
   - **Email with instructions**
   - Include GitHub repo link
   - Include deployment guide
   - Include support email

**Email Template**:
```
Hi {customer_name},

Thanks for purchasing {product_name}!

Your dashboard is ready:
👉 GitHub Repo: [your-repo-link]
👉 Live Demo: [demo-link]

WHAT'S INCLUDED:
✅ Complete source code
✅ Documentation
✅ Deployment guide
✅ 30-day support

NEXT STEPS:
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Customize to your needs

NEED HELP?
Reply to this email anytime!

Happy building!
Brian
```

- **Fee**: 10% per sale
